# SearchAgent-RL 项目设计文档

## 1. 项目定位

SearchAgent-RL 是一个基于 Search-R1 思想的大语言模型自主检索 Agent
后训练项目。

本项目不追求对 Search-R1
工业级训练框架的完全复现，而是围绕其核心思想，构建一个可复现的大模型
Agent 训练流程，重点研究：

-   Teacher-generated Agent Trajectory 数据构建；
-   Agentic Supervised Fine-Tuning（Agentic SFT）；
-   Group Relative Policy Optimization（GRPO）强化学习优化。

项目目标是实现一个能够自主判断检索需求、调用搜索工具并利用外部信息完成复杂问答任务的语言模型
Agent。

------------------------------------------------------------------------

# 2. 项目背景

传统大语言模型主要依赖参数化知识完成回答：

    Question

    ↓

    LLM

    ↓

    Answer

这种方式存在：

-   知识更新困难；
-   无法访问实时信息；
-   面对复杂问题缺少外部信息获取能力；
-   模型无法自主决定是否需要检索。

传统 RAG 方法通常由外部 Retriever 决定检索过程：

    Question

    ↓

    Retriever

    ↓

    Retrieved Documents

    ↓

    LLM

    ↓

    Answer

其中检索行为由固定流程控制，模型本身缺少主动决策能力。

Search Agent 希望让 LLM 成为主动决策者：

    Question

    ↓

    LLM Agent

    ↓

    Search Action

    ↓

    Observation

    ↓

    Reasoning

    ↓

    Answer

模型能够自主学习：

-   是否需要搜索；
-   搜索什么内容；
-   如何利用检索结果。

# 4. 数据设计

## 4.1 数据来源

计划使用开放域问答数据集：

-   Natural Questions (NQ)
-   HotpotQA

数据主要包含：

-   question
-   answer
-   supporting information（部分数据集）

统一转换为：

``` json
{
    "question": "",
    "answer": ""
}
```

------------------------------------------------------------------------

## 4.2 数据划分

数据需要划分为不同训练阶段：

    Dataset

    ├── Agentic SFT Dataset
    │
    ├── GRPO Dataset
    │
    └── Validation Dataset

其中：

### Agentic SFT Dataset

用于生成 Teacher trajectory。

目标：

让模型学习 Agent 基础行为。

------------------------------------------------------------------------

### GRPO Dataset

用于强化学习。

目标：

让模型自主探索更优搜索策略。

------------------------------------------------------------------------

### Validation Dataset

用于评价：

-   答案准确率；
-   搜索能力；
-   推理能力。

------------------------------------------------------------------------

# 5. Agent环境设计

## 5.1 Agent状态

Agent状态包含：

-   当前问题；
-   历史对话；
-   已获得搜索信息。

形式：

    State =
    Question + History + Observation

------------------------------------------------------------------------

## 5.2 Agent动作

Agent主要包含两类动作：

### Search Action

模型生成：

    <search>
    query
    </search>

系统执行搜索并返回结果。

### Answer Action

模型生成：

    <answer>
    final answer
    </answer>

完成任务。

------------------------------------------------------------------------

## 5.3 Agent Trajectory

完整轨迹：

    Question

    ↓

    Reasoning

    ↓

    Search Action

    ↓

    Observation

    ↓

    Reasoning

    ↓

    Answer

表示为：

    (state, action, observation, reward)

------------------------------------------------------------------------

# 6. Teacher Trajectory Generation

直接对基础模型进行 GRPO 训练存在困难：

-   模型不会正确调用工具；
-   搜索行为探索空间过大；
-   reward 信号稀疏。

因此首先利用 Teacher LLM 生成高质量 Agent 示范轨迹。

流程：

    Question

    ↓

    Teacher LLM

    ↓

    Search Interaction

    ↓

    Agent Trajectory

    ↓

    SFT Dataset

Teacher trajectory 用于：

-   提供搜索行为示范；
-   初始化 Agent 能力；
-   降低强化学习探索难度。

------------------------------------------------------------------------

# 7. Agentic SFT设计

传统 SFT：

    Question → Answer

本项目：

    Question → Agent Trajectory

训练目标：

学习：

\[ P(Trajectory\|Question) \]

模型学习：

-   工具调用格式；
-   搜索行为；
-   信息利用；
-   多步推理。

训练方式：

-   HuggingFace Transformers；
-   PEFT LoRA。

------------------------------------------------------------------------

# 8. GRPO强化学习设计

Agentic SFT 后，模型具备基础搜索能力。

进一步使用 GRPO 优化：

    Question

    ↓

    Multiple Rollouts

    ↓

    Reward Calculation

    ↓

    GRPO Update

奖励函数初步考虑：

## Answer Reward

判断最终答案是否正确。

## Format Reward

判断是否符合 Agent 输出格式。

## Tool Usage Reward

判断搜索行为是否有效。

最终优化目标：

提升：

-   搜索决策能力；
-   推理能力；
-   答案准确率。

------------------------------------------------------------------------

# 9. 实验设计

为了分析不同训练阶段的贡献，设计：

  实验                 方法            目的
  -------------------- --------------- ------------------
  Base Model           未训练模型      测试初始能力
  QA-SFT               普通问答微调    分析传统SFT效果
  Agentic-SFT          Agent轨迹微调   验证轨迹监督效果
  Agentic-SFT + GRPO   强化学习优化    验证最终方案

主要指标：

-   Answer Accuracy；
-   Exact Match；
-   Search Success Rate；
-   Tool Calling Ability。

------------------------------------------------------------------------

# 10. 技术方案

## 模型

初步考虑：

-   Qwen系列模型。

## 微调方式

采用：

-   LoRA / QLoRA。

## 训练框架

初步采用：

-   Transformers；
-   PEFT；
-   TRL。

暂不直接使用 veRL。

原因：

第一阶段目标是完成完整 Agent RL
Pipeline，而不是复现工业级分布式训练框架。
