# SearchAgent-RL 数据设计文档

## 1. 数据工程目标

数据工程阶段的目标是将原始开放域问答数据转换为适用于 Agent
后训练的数据格式。

整体流程：

    Raw QA Dataset
            ↓
    Data Cleaning
            ↓
    Unified QA Format
            ↓
    Dataset Split
            ↓
    Agentic SFT Dataset / GRPO Dataset / Validation Dataset

本阶段重点解决：

-   原始 QA 数据如何转换为 Agent 训练数据；
-   Teacher LLM 如何生成 Agent trajectory；
-   SFT 和 GRPO 两个阶段的数据如何组织。

------------------------------------------------------------------------

## 2. 数据来源

计划使用：

-   Natural Questions (NQ)
-   HotpotQA

NQ 主要用于开放域检索问答，HotpotQA 用于多跳推理和复杂检索任务。

------------------------------------------------------------------------

## 3. 统一 QA 数据格式

不同数据集转换为：

``` json
{
    "id": "nq_00001",
    "dataset": "nq",
    "question": "Who wrote Frankenstein?",
    "answer": "Mary Shelley"
}
```

字段：

-   id：样本唯一标识；
-   dataset：数据来源；
-   question：用户问题；
-   answer：标准答案。

------------------------------------------------------------------------

## 4. Teacher Agent Trajectory 数据

基础模型通常缺少工具调用能力，因此使用 Teacher LLM 生成 Agent 行为轨迹。

流程：

    Question
        ↓
    Teacher LLM
        ↓
    Search Interaction
        ↓
    Agent Trajectory
        ↓
    SFT Dataset

Teacher采用：

-   DeepSeek API / GPT API

原因：

-   提供高质量示范数据；
-   避免训练Teacher消耗大量资源；
-   重点研究Student Agent能力提升。

Trajectory包含：

-   reasoning；
-   search action；
-   tool observation；
-   final answer。

示例：

``` json
{
 "question": "Who wrote Frankenstein?",
 "trajectory": [
   {
    "action": "search",
    "query": "author of Frankenstein"
   },
   {
    "action": "answer",
    "content": "Mary Shelley"
   }
 ]
}
```

------------------------------------------------------------------------

## 5. Agentic SFT 数据设计

传统SFT：

    Question → Answer

Agentic SFT：

    Question → Agent Trajectory

训练目标：

学习：

\[ P(Trajectory\|Question) \]

数据格式：

``` json
{
 "messages":[
   {
    "role":"user",
    "content":"Question"
   },
   {
    "role":"assistant",
    "content":"Agent trajectory"
   }
 ]
}
```

训练方式：

-   Transformers；
-   PEFT LoRA；
-   SFTTrainer。

------------------------------------------------------------------------

## 6. GRPO 数据设计

GRPO阶段不使用Teacher轨迹。

原因：

GRPO需要模型自主探索。

流程：

    Question
        ↓
    Student Rollout
        ↓
    Multiple Trajectories
        ↓
    Reward
        ↓
    GRPO Update

输入：

``` json
{
 "question":"...",
 "answer":"..."
}
```

模型生成多个候选轨迹，根据reward优化。

------------------------------------------------------------------------

## 7. 数据划分

原则：

-   SFT和GRPO数据互斥；
-   Validation不参与训练；
-   保证实验公平。

结构：

    Dataset

    ├── Agentic SFT Dataset
    ├── GRPO Dataset
    └── Validation Dataset
